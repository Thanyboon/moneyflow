# MONEYFLOW

PWA starter สำหรับแอปวางแผนการเงินส่วนบุคคล

## ไฟล์
- `index.html` หน้าแอป
- `style.css` รูปแบบ Responsive และ Dark Mode
- `app.js` พฤติกรรมหน้าแอป
- `manifest.json` ข้อมูล PWA
- `service-worker.js` แคชหน้าแอปเพื่อเปิดออฟไลน์บางส่วน
- `icons/` ไอคอนแอป

## สถานะ
นี่คือโครงสร้าง PWA เริ่มต้น ยังไม่เชื่อมต่อ Google Sheets และยังไม่ควรใช้บันทึกข้อมูลการเงินจริง จนกว่าจะตั้งค่าการยืนยันตัวตน Backend อย่างปลอดภัย

เผยแพร่ด้วย GitHub Pages ผ่าน HTTPS
